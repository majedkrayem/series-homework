# series-homework 

פרויקט זה עוסק בניהול סדרות טלוויזיה באמצעות JavaScript ו־JSON. הפרויקט כולל עבודה עם מערכים ואובייקטים, עדכון נתונים ללא שינוי המקור ותיקון באגים.

איך מריצים את הבדיקות?
מריצים בטרמינל:


bash
node check.js

שאלות
1. בפונקציה addEpisode לא מספיק לכתוב { ...show }. אילו אובייקטים ומערכים יצרתם מחדש, ולמה?
יצרתי מערך חדש של הסדרות, כדי לא לשנות את המערך המקורי. בנוסף, יצרתי עותק חדש של הסדרה שעודכנה, מערך עונות חדש, עותק חדש של העונה הרלוונטית ומערך פרקים חדש. כך השינויים מתבצעים רק בעותקים ולא בנתונים המקוריים.

2. בתקלה #3 העמית כן עשה עותק עם ... . למה זה לא עזר?
העמית יצר עותק של אובייקט הסדרה בלבד באמצעות spread operator. אבל מערך העונות והמערך של הפרקים עדיין היו משותפים למקור. לכן, הוספת פרק שינתה גם את הנתונים המקוריים.
